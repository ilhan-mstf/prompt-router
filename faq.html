Frequently Asked Questions

Everything you need to know about Prompt Router, model comparisons, privacy, and curated prompt libraries.

What is Prompt Router? +

Prompt Router is a free, web-based tool designed to make multi-LLM workflows effortless. Instead of writing a prompt, copying it, switching browser tabs, and pasting it across multiple AI interfaces, Prompt Router lets you write your prompt once and launch it into 12 leading AI providers with a single click or keyboard shortcut.

This allows you to quickly compare how different models interpret, reason, and solve your specific prompt side-by-side.

Is Prompt Router completely free to use? +

Yes, Prompt Router is 100% free with no subscriptions, paid tiers, or hidden fees. All features — including routing to all 12 AI models, accessing all 11 prompt libraries, and saving personal prompts — are completely accessible to everyone.

Do I need to create an account or sign in? +

No. Prompt Router does not require an account, email address, password, or login. You can immediately open the tool in any modern web browser and start dispatching prompts.

Is my prompt data private and secure? +

Yes. Prompt Router is designed with a strict local-first privacy architecture:

  • No Backend Storage: We do not operate a database to capture or log your prompt text.
  • Zero Tracking: We do not track or sell user query telemetry.
  • Browser-Only: Your prompts and saved items stay exclusively within your local browser's storage. When you click a provider, your prompt is transmitted directly to that provider's web application.

How does prompt routing work under the hood? +

Prompt Router uses official deep linking mechanisms and URL query parameters supported by each AI provider (e.g., ?q=YOUR_PROMPT). When you choose a provider, Prompt Router encodes your prompt text and opens that provider's native web app in a new tab with your prompt already in the input box.

For providers that do not accept URL parameters, Prompt Router automatically copies your prompt to your clipboard so you can simply paste (⌘V / Ctrl+V) immediately upon arrival.

What are Prompt Libraries? +

Prompt Libraries are curated collections containing over 260 domain-specific prompt engineering templates across 11 professional fields:

  • Dev & Coding: Debugging, code review, architecture, refactoring, and DevOps.
  • Writing & Content: Essays, copywriting, editing, tone shifting, and storytelling.
  • Marketing & Growth: SEO, advertising copy, campaign planning, and email marketing.
  • Job Search: Resumes, cover letters, mock interview practice, and negotiation.
  • Startup & Founders: Pitch decks, idea validation, competitive analysis, and GTM.
  • Data Analysis: SQL queries, Python analysis, statistics, and visualization.
  • Design & UX: UI review, user personas, wireframe specifications, and accessibility.
  • Student & Study: Socratic tutoring, exam prep, flashcards, and essay outlines.
  • Productivity: Daily planning, meeting summaries, task triage, and habit tracking.
  • Legal & Contracts: Clause analysis, NDA drafting, compliance, and contract breakdown.
  • Sales & Deals: Cold outreach, discovery calls, objection handling, and proposal closing.
Do I need to provide API keys? +

No. Prompt Router connects directly to the consumer web interfaces of supported AI models. You never need to generate, pay for, or paste API keys. If a model requires an account (such as OpenAI or Anthropic), you simply log into their site normally in your browser.

Can I save prompts or view my history? +

Yes. The collapsible sidebar provides full management for your prompts:

  • Saved Prompts: Click ⌘S or the Save button to keep your favorite prompts organized.
  • Prompt History: Every dispatched prompt is saved locally in your session history so you can restore earlier prompts anytime.
  • Clear History: You can wipe your history at any time with one click.
What keyboard shortcuts are available? +

Prompt Router is designed for keyboard-first efficiency:

  • ⌘ Enter / Ctrl Enter: Dispatch prompt to the currently selected AI model.
  • ⌘ C / Ctrl C: Copy the prompt to your clipboard.
  • ⌘ S / Ctrl S: Save the current prompt to your Saved list.
  • ⌘ B / Ctrl B: Toggle the left navigation sidebar.
  • Esc: Clear current prompt or focus a new prompt canvas.
